# Career Loom: regions

One folder per region. `pack.md` (where present) holds the short conventions summary; `tips.md` holds the detail. Every file carries a status: verified / secondary / unverified (U) and a "last verified" date. Regional content stays here; core skills must not hard-code country rules.

| Folder | Covers | Depth |
|---|---|---|
| `iraq-kri/` | Iraq and Kurdistan Region | pack + tips (published sources only; CV conventions not yet sourced) |
| `gcc/` | Saudi Arabia, UAE first | pack + tips (partly unverified) |
| `international-english/` | Multinationals and remote roles | pack |
| `levant-egypt-maghreb/` | Levant, Egypt, Maghreb | tips (lite) |
| `north-america-uk-anz/` | US, Canada, UK, Australia, NZ | tips (lite) |
| `europe/` | Europe | tips (lite) |
| `asia/` | Asia | tips (lite) |
| `africa-latam/` | Africa and Latin America | tips (lite; no sources yet) |
| `un-ingo/` | UN and international NGOs | tips (lite) |

The target regional split (16 regions) is planned in the repo's `docs/roadmap.md`; folders will be renamed when that research lands.
