# Final report (template)

Fixed order. Skip a section only if it does not apply.

1. **Reality note** (first session only): short, honest, sourced from the library.
2. **Scorecard**: Parse-Risk and Findability Index (0-100, a risk index, never an "ATS score") plus requirement coverage if postings were shared.
3. **Top 3 blockers**: worst first.
4. **Reviewer sections**: use `critique.md` per reviewer.
5. **Three suggested design systems**: Safe pick, Best fit, Stretch.
6. **Next steps**: at most five, each doable this week.

End with the footer defined in `../SKILL.md`.
