# C6 Metric Spotlight

ATS tier: **B** (single column with colour). Status: finished. Tokens: `tokens.json` (schema in `systems/TOKENS.md`).

## Use it for
Roles with a few strong numbers to show (support, sales, operations). Highlights come first as large numerals with a text label.

## Layout
One column. A 'Highlights' row of 2 to 4 cards sits above the profile; each card is a value and a text label taken from facts already in the CV body, with estimates marked ~. Green accent. Without highlights the section is simply absent.

## Fonts (OFL, by role)
Inter (Latin, Cyrillic) with IBM Plex Sans Arabic for Arabic script; Noto Sans SC and Noto Sans Devanagari (downloaded on demand) for Chinese and Devanagari. Mono role: IBM Plex Mono.

## RTL variant
`--rtl auto` follows the CV language. Values are isolated left-to-right so '~40' does not flip. Emails, URLs and phone numbers stay left-to-right inside the line. Arabic uses a taller line height and no ligatures so that extracted text keeps its letter order. Sorani is labelled **needs native review**.

## Rules this design never breaks
No skill bars or percentages, no logos, no photo, contact details in the body text (never only in a header or footer), no information only in a graphic.

## Word output
Yes: single column, same section order, real headings and bullets (verified in LibreOffice only, not Word).
