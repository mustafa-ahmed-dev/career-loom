# C8 Warm Editorial

ATS tier: **B** (single column with colour). Status: finished. Tokens: `tokens.json` (schema in `systems/TOKENS.md`).

## Use it for
Writers, editors, teachers and cultural roles: a warm cream page with serif headings.

## Layout
One column on a cream page (#fbf6ee, bleeds to the page edge), serif headings in brown-red, sans-serif body, dash bullets. Print uses more ink than white-paper designs; use P3 or P1 for black-and-white printing.

## Fonts (OFL, by role)
Source Serif 4 / Noto Naskh Arabic for display and headings; Inter / IBM Plex Sans Arabic for body. Noto Sans SC and Noto Sans Devanagari downloaded on demand.

## RTL variant
`--rtl auto` follows the CV language. The cream background mirrors nothing; text mirrors. Emails, URLs and phone numbers stay left-to-right inside the line. Arabic uses a taller line height and no ligatures so that extracted text keeps its letter order. Sorani is labelled **needs native review**.

## Rules this design never breaks
No skill bars or percentages, no logos, no photo, contact details in the body text (never only in a header or footer), no information only in a graphic.

## Word output
Yes: single column, same section order, real headings and bullets (verified in LibreOffice only, not Word).
