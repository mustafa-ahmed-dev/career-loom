# C5 Ribbon Sections

ATS tier: **B** (single column with colour). Status: finished. Tokens: `tokens.json` (schema in `systems/TOKENS.md`).

## Use it for
A structured, easy-to-scan page for managers and coordinators.

## Layout
One column. Each section heading sits on a pale blue ribbon (#dce8f4) with dark blue text. Ribbons are CSS backgrounds, so text extracts normally.

## Fonts (OFL, by role)
Inter (Latin, Cyrillic) with IBM Plex Sans Arabic for Arabic script; Noto Sans SC and Noto Sans Devanagari (downloaded on demand) for Chinese and Devanagari. Mono role: IBM Plex Mono.

## RTL variant
`--rtl auto` follows the CV language. Ribbons run the full column width in both directions. Emails, URLs and phone numbers stay left-to-right inside the line. Arabic uses a taller line height and no ligatures so that extracted text keeps its letter order. Sorani is labelled **needs native review**.

## Rules this design never breaks
No skill bars or percentages, no logos, no photo, contact details in the body text (never only in a header or footer), no information only in a graphic.
