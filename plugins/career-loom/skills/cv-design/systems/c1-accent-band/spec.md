# C1 Accent Band

ATS tier: **B** (single column with colour). Status: finished. Tokens: `tokens.json` (schema in `systems/TOKENS.md`).

## Use it for
Sending to a person when you want a confident coloured header but a fully plain body. Safe for most portals because the body is a single column.

## Layout
A full-width navy band holds name, headline and contact; the body is one column with ruled upper-case headings. The band bleeds to the page edge on every print.

## Fonts (OFL, by role)
Inter (Latin, Cyrillic) with IBM Plex Sans Arabic for Arabic script; Noto Sans SC and Noto Sans Devanagari (downloaded on demand) for Chinese and Devanagari. Mono role: IBM Plex Mono.

## RTL variant
`--rtl auto` follows the CV language. The band stays full width; text inside mirrors. Emails, URLs and phone numbers stay left-to-right inside the line. Arabic uses a taller line height and no ligatures so that extracted text keeps its letter order. Sorani is labelled **needs native review**.

## Rules this design never breaks
No skill bars or percentages, no logos, no photo, contact details in the body text (never only in a header or footer), no information only in a graphic.
