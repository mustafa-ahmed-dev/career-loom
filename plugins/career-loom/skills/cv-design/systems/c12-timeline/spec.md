# C12 Timeline

ATS tier: **C** (two columns or grid, for people). Status: finished. Tokens: `tokens.json` (schema in `systems/TOKENS.md`). A-rated plain twin: **P1 Plain Master**, produced automatically.

## Use it for
Career histories where the sequence matters. **Never upload it to a portal**: the P1 twin is produced automatically.

## Layout
Dates sit in a left column beside a thin teal line with a dot per entry (education, projects and certificates too). The line and dots are CSS backgrounds, decoration only: every date is also text in its entry. Reading order in the file is title, then dates.

## Fonts (OFL, by role)
Inter (Latin, Cyrillic) with IBM Plex Sans Arabic for Arabic script; Noto Sans SC and Noto Sans Devanagari (downloaded on demand) for Chinese and Devanagari. Mono role: IBM Plex Mono.

## RTL variant
`--rtl auto` follows the CV language. The date column and line move to the right edge. Emails, URLs and phone numbers stay left-to-right inside the line. Arabic uses a taller line height and no ligatures so that extracted text keeps its letter order. Sorani is labelled **needs native review**.

## Rules this design never breaks
No skill bars or percentages, no logos, no photo, contact details in the body text (never only in a header or footer), no information only in a graphic.

## Word output
Best effort: a single column in the same order as the A twin, with the accent colours. There is no real sidebar or grid in Word, by design.
