# C7 Brand Kit

ATS tier: **B** (single column with colour). Status: finished. Tokens: `tokens.json` (schema in `systems/TOKENS.md`).

## Use it for
A personal-brand look: one accent colour carried through headings and skill pills.

## Layout
One column. Headings have a coloured bar at the start edge; skills are text pills on a pale purple tint (#efe6f7). The pills are plain text, there are no levels or bars.

## Fonts (OFL, by role)
Inter (Latin, Cyrillic) with IBM Plex Sans Arabic for Arabic script; Noto Sans SC and Noto Sans Devanagari (downloaded on demand) for Chinese and Devanagari. Mono role: IBM Plex Mono.

## RTL variant
`--rtl auto` follows the CV language. The heading bar moves to the right edge. Emails, URLs and phone numbers stay left-to-right inside the line. Arabic uses a taller line height and no ligatures so that extracted text keeps its letter order. Sorani is labelled **needs native review**.

## Rules this design never breaks
No skill bars or percentages, no logos, no photo, contact details in the body text (never only in a header or footer), no information only in a graphic.
