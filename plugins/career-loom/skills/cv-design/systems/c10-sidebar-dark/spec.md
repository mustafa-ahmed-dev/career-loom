# C10 Sidebar Dark

ATS tier: **C** (two columns or grid, for people). Status: finished. Tokens: `tokens.json` (schema in `systems/TOKENS.md`). A-rated plain twin: **P1 Plain Master**, produced automatically.

## Use it for
CVs sent to a person where you want a strong, dark sidebar. **Never upload it to a portal**: the plain P1 twin is produced automatically.

## Layout
A 56 mm navy sidebar (#17324d) with white text holds contact, skills, languages and certificates; the wide column holds the rest. The tint runs the full page height on every page. It uses more ink than light designs.

## Fonts (OFL, by role)
Inter (Latin, Cyrillic) with IBM Plex Sans Arabic for Arabic script; Noto Sans SC and Noto Sans Devanagari (downloaded on demand) for Chinese and Devanagari. Mono role: IBM Plex Mono.

## RTL variant
`--rtl auto` follows the CV language. The sidebar moves to the right edge. Emails, URLs and phone numbers stay left-to-right inside the line. Arabic uses a taller line height and no ligatures so that extracted text keeps its letter order. Sorani is labelled **needs native review**.

## Rules this design never breaks
No skill bars or percentages, no logos, no photo, contact details in the body text (never only in a header or footer), no information only in a graphic.

## Word output
Best effort: a single column in the same order as the A twin, with the accent colours. There is no real sidebar or grid in Word, by design.
