# P6 Technical Compact

ATS tier: **A** (plain single column). Status: finished. Tokens: `tokens.json` (schema in `systems/TOKENS.md`).

## Use it for
Engineers and analysts with long skills lists: compact spacing, skills straight after the profile, tool names set in a monospaced face.

## Layout
One column, 9.5 pt text, 12-14 mm margins, skills section second, skills shown in IBM Plex Mono. Black and grey only. The smallest body text is 9.5 pt; nothing is set below 8.5 pt.

## Fonts (OFL, by role)
Inter (Latin, Cyrillic) with IBM Plex Sans Arabic for Arabic script; Noto Sans SC and Noto Sans Devanagari (downloaded on demand) for Chinese and Devanagari. Mono role: IBM Plex Mono.

## RTL variant
`--rtl auto` follows the CV language. Tool names stay left-to-right; labels and prose mirror. Emails, URLs and phone numbers stay left-to-right inside the line. Arabic uses a taller line height and no ligatures so that extracted text keeps its letter order. Sorani is labelled **needs native review**.

## Rules this design never breaks
No skill bars or percentages, no logos, no photo, contact details in the body text (never only in a header or footer), no information only in a graphic.
