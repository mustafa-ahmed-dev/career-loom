# P1 Plain Master

ATS tier: **A** (plain single column). Status: finished. Tokens: `tokens.json` (schema in `systems/TOKENS.md`).

## Use it for
The safe default: online portals, large employers, any region, any seniority. If you are unsure, start here.

## Layout
- One column, A4, margins 16 / 18 / 16 mm. Name, headline, then contact on one wrapped line in the body.
- Section headings are small upper-case Inter Bold (Latin and Cyrillic only; other scripts use weight) with a thin rule below.
- Entries: title and dates on one line, employer and place below, bullets underneath. Skills and languages run inline.
- Section order: profile, experience, projects, education, volunteering, publications, skills, certificates, languages.
- Colour: black text, grey secondary text. Nothing depends on colour.

## Fonts (OFL, by role)
Display, heading, body: Inter (Latin, Cyrillic) with IBM Plex Sans Arabic for Arabic script; Noto Sans SC and Noto Sans Devanagari (downloaded on demand) for Chinese and Devanagari. Mono role: IBM Plex Mono.

## RTL variant
`--rtl auto` follows the CV language (Arabic, Sorani, Persian, Urdu, Hebrew). The whole page mirrors: alignment, dates, bullets. Emails, URLs and phone numbers stay left-to-right inside the line. Arabic uses a taller line height and no ligatures so that copied or extracted text keeps its letter order. Sorani is labelled **needs native review**.

## Rules this design never breaks
No skill bars or percentages, no logos, no graphics, no photo, contact details in the body (never only in a header or footer), tables and text boxes are not used.
