# C15 Swiss Grid

ATS tier: **C** (two columns or grid, for people). Status: finished. Tokens: `tokens.json` (schema in `systems/TOKENS.md`). A-rated plain twin: **P1 Plain Master**, produced automatically.

## Use it for
A modern, editorial grid for designers, architects and analysts. **Never upload it to a portal**: the P1 twin is produced automatically.

## Layout
A 36 mm label column carries each section name in small red upper-case type; content sits in the wide column beside it, with a black rule above every section. 32 pt name.

## Fonts (OFL, by role)
Inter (Latin, Cyrillic) with IBM Plex Sans Arabic for Arabic script; Noto Sans SC and Noto Sans Devanagari (downloaded on demand) for Chinese and Devanagari. Mono role: IBM Plex Mono.

## RTL variant
`--rtl auto` follows the CV language. Labels move to the right edge. Emails, URLs and phone numbers stay left-to-right inside the line. Arabic uses a taller line height and no ligatures so that extracted text keeps its letter order. Sorani is labelled **needs native review**.

## Rules this design never breaks
No skill bars or percentages, no logos, no photo, contact details in the body text (never only in a header or footer), no information only in a graphic.
