# Interview rubric (template)

Write this before asking each question. Keep it hidden until scoring.

| Field | Content |
|---|---|
| Question | |
| Competency | e.g. ownership, prioritisation, communication, technical depth |
| Strong answer shows (3) | specific situation, own action stated as "I", measurable result |
| Weak answer shows | vague "we", no result, memorised phrases |
| Follow-ups by level | L1 none; L2 one clarifier; L3 "what exactly did you do?", "how did you measure it?"; L4 trade-offs, "why not X?", checks CV claims; L5 interruptions, devil's advocate |

Scale (fixed at every level): 1-2 off-topic or harmful; 3-4 weak; 5-6 acceptable; 7-8 strong; 9-10 exceptional. Scores are practice feedback, not predictions.
