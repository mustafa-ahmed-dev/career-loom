# Fact Bank (template)

One row per fact. A document may use only rows listed here. Source is one of: `user` (stated in chat), `doc` (from an uploaded file, name it), `est` (user estimate, shown with "~").

| # | Type | Fact | Source | Evidence or note | Skill state |
|---|---|---|---|---|---|
| 1 | Role | Title, employer, start-end dates | user / doc | | n/a |
| 2 | Achievement | What changed, by how much, over what period | user / doc / est | How measured | n/a |
| 3 | Credential | Degree or licence, issuer, year | doc | Certificate seen? | n/a |
| 4 | Skill | Skill name | user | Where it was used | Evidenced / Latent / Gap |

Rules: Latent skills need one targeted question first. Gap skills never go on the document; offer a "currently learning" line instead.
