# Europe (light pack)

## General EU
- A Europass CV is accepted, and expected for EU institutions. Its photo is optional and best omitted for EU institutions. [S090]
- Languages section with CEFR levels (A1–C2) is expected in multilingual markets.
- GDPR applies: collect and keep only the personal data you need.
- A motivation letter is often expected.

## Germany, Austria, Switzerland (DACH)
- Lebenslauf (CV) in table style with a date column.
- Photo common but optional.
- Signature and date at the end are traditional. (U)
- Job boards: StepStone (no public API found) [S122]; XING (API retired) [S121]; referrals.
- 65% of job seekers report being ghosted after an interview. [S044]

## France (U)
- 1-page CV.
- Photo common but optional.
- Lettre de motivation in a formal register.

## Spain (U)
- Currículum; photo common but optional.
- Job board: InfoJobs, which has an official API (no storing or exporting data). [S106, S107]

## Russia and CIS (U)
- Резюме (CV) mostly posted on hh.ru; photo common.
- hh.ru closed its public API in April 2026. [S115, S116]
- Personal data law: 152-FZ.
