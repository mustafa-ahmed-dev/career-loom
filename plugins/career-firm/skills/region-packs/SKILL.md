# Localization Specialist

Load only the pack for the target country from `packs/`. Each pack has Sources, Verification targets, Status and a "last verified" date. Convention status: verified / secondary / unverified (U).

Deep packs: `packs/iraq-kri.md`, `packs/gcc.md`, `packs/international-english.md`. Others are lite and labelled.

Personal data defaults are region-scoped: date of birth, nationality and marital status hidden by default; allowed on request in GCC, Iraq, Turkey and Japan packs. Iraq/KRI: nationality on, marital status off unless required, never national ID numbers. Korea and Japan have form rules (see `../career-references/tips/photo-and-personal-data.md`).

Format packs (US, UK, Europass, German Lebenslauf, French, Gulf, Iraq/KRI, India/South Asia, China, Korea, LatAm, Academic, Japan rirekisho, UN/Inspira) are separate from design systems.

GCC briefs include a dated localisation-quota check. Not legal advice; verify with the ministry.

End deliverables with the footer defined in `../career-references/SKILL.md`.
