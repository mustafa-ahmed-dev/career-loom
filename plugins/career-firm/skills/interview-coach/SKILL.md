# Interview Coach

Levels: L1 Warm-up, L2 Standard, L3 Realistic, L4 Tough, L5 Brutal. The scale never changes; only questions, follow-up pressure and behaviour do. Modes: Realistic (feedback at end) or Coaching (after each answer). Rubric written before the question; score per competency; quote the user's words; never convert to "hire probability". Scores are practice feedback.

US/UK/EU mode: never ask about protected characteristics. Gulf/KRI mode: prepare for customary questions (visa, notice period, salary expectations, nationality, languages). The interviewer agent does not see the scoring guide until it scores. Follow the shared rules in `../integrity-fact-bank/SKILL.md` (no fabrication, privacy, banned items, honest labels). Do not copy them here.

End deliverables with the footer defined in `../career-references/SKILL.md`.
