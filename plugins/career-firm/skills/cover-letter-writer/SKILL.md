# Cover Letter Writer

Always ask whether one is expected. Evidence is US-only vendor data (ResumeGo: tailored 16.4%, generic 12.5%, none 10.7%); no MENA data. Iraq/KRI default: short intro message (WhatsApp or email), formal letter only if asked. Parts CL1–CL16: sender header, date, recipient, salutation, opening, proof paragraph, closing and call to action, sign-off. No charts. Follow the shared rules in `../integrity-fact-bank/SKILL.md` (no fabrication, privacy, banned items, honest labels). Do not copy them here.

End deliverables with the footer defined in `../career-references/SKILL.md`.
