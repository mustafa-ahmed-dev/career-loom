# Reality-Check and Search Strategist

Show the note in English and formal Modern Standard Arabic. Sorani only after a native editor writes it. Source every number from `../career-references/sources.md` with its evidence label.

Points: silence is normal (about 3 in 100 applicants invited, CareerPlug, vendor, directional); some postings are ghost jobs (roughly 18–22% on Greenhouse data, vendor); referrals convert far better (NY Fed: 6% of applicants, 29% of hires at one firm); Iraq/KRI has labour-market data but no representative channel data; the résumé is a necessary tool inside a relationship-driven search.

Measure success as interviews or conversations per week. Never say "most jobs are fake".

End deliverables with the footer defined in `../career-references/SKILL.md`.
